This website is part of the MAKAAO project. MAKAAO stands for "MApping Knowledge about Autoimmune diseases, Autoantibodies, and Other clinical signs". It was started by Maud de Dieuleveult (Institut Imagine) and Adrien Coulet (Inria Paris, HeKA) in 2021. Currently and up to 2026, the project is mainly driven by an ongoing PhD thesis by Fabien Maury, funded by FSMR BRAIN-TEAM & Filnemus.

The website makes available the MAKAAO knowledge graph which includes data from a small, core manually curated dataset; and in the future it will be enriched by relations automatically extracted from scientific literature and patients' EHR.

You can find our code on our GitHub repository.

This website is a work in progress and may change in the future.
